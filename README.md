# CHX-chase-decay-analysis
An end-to-end R analysis pipeline for quantitative cycloheximide (CHX) chase mass spectrometry data.

This pipeline calculates protein turnover kinetics, estimates half-lives ($t_{1/2}$) with confidence intervals, performs rigorous statistical hypothesis testing for differential decay rates between experimental conditions (e.g., Wild-Type/Parental vs. Knockout), and generates publication-ready vector figures (SVG).

## Input Data Format

The pipeline expects standard TSV outputs generated by DIA-NN:

1. **`report.pr_matrix.tsv`** (Precursor matrix)

2. **`report.pg_matrix.tsv`** (Protein group matrix)

### Default Experimental Layout

The default scripts assume an 18-sample vs. 18-sample design (36 samples total):
- **Time points**: 0 h, 1 h, 2 h, 4 h, 6 h, 8 h
- **Replicates**: 3 biological replicates per time point
- **WT / Parental**: Columns 7 to 24 of `pg_matrix` (ordered $0\text{h}\times 3, 1\text{h}\times 3, \dots, 8\text{h}\times 3$)
- **KO / Perturbation**: Columns 25 to 42 of `pg_matrix` (ordered $0\text{h}\times 3, 1\text{h}\times 3, \dots, 8\text{h}\times 3$)

### Step 1: Sample-Specific Peptide Filtering

Filters protein abundances such that any protein group with fewer than `min_peptides` (default: 2) unique proteotypic peptides detected with positive intensity in a given sample is converted to `NA` for that sample.

**Run from command line:**

```bash
Rscript filter_pg_by_peptide_count.R [pr_matrix.tsv] [pg_matrix.tsv] [output.tsv] [min_peptides]
```

Using default arguments:

```bash
Rscript filter_pg_by_peptide_count.R
```

**Defaults:**
- `pr_path`: `report.pr_matrix.tsv`
- `pg_path`: `report.pg_matrix.tsv`
- `output_path`: `report.pg_matrix.filtered_min2peptides.tsv`
- `min_peptides`: `2`

**Output:**
- Generates `report.pg_matrix.filtered_min2peptides.tsv` and prints a summary of filtered values to the console.

---

### Step 2: Half-Life & Differential Decay Statistics

Performs kinetic modeling and tests for differential degradation rates across the entire proteome.

**Run from command line:**

```bash
Rscript CHX_p_value.R
```

**Key Operations:**
1. Loads `report.pg_matrix.filtered_min2peptides.tsv`.
2. Excludes ambiguous multiprotein entries (IDs containing `;`) and cRAP contaminants (`cRAP-*`).
3. Retains proteins with $\ge 2$ global proteotypic sequences.
4. Requires $\ge 2$ valid replicates per time point; requires $\ge 2$ valid time points per condition for regression.
5. Fits $\log_2$ linear regression for WT and KO separately to derive slopes and half-lives.
6. Fits an interaction model ($\log_2(\text{Intensity}) \sim \text{Time} \times \text{Group}$) using all individual replicates to test whether degradation slopes differ significantly.
7. Corrects interaction $p$-values across all proteins using Benjamini–Hochberg FDR.

**Output:**
- `HalfLife_AllProteins.xlsx`: Comprehensive Excel workbook containing half-lives, slopes, confidence intervals, 0h fold changes, raw $p$-values, and BH-adjusted FDR values.

---

### Step 3: Decay Curve Plotting

Generates publication-quality vector figures (SVG) for individual target proteins, incorporating error bars, exponential decay curves, and trajectory-wide statistical significance brackets.

**Usage:**

```bash
Rscript CHX_decay_plot.R [gene_symbol] [--global]
```

**Examples:**

1. Plot decay kinetics for a specific gene (e.g., `IP6K2`):
   ```bash
   Rscript CHX_decay_plot.R IP6K2
   ```
   *Generates `2026Figure_CHX_IP6K2.svg` ($88 \times 70\text{ mm}$).*

2. Plot another gene:
   ```bash
   Rscript CHX_decay_plot.R TP53
   ```

3. Generate both the target gene plot and the global proteome median control plot:
   ```bash
   Rscript CHX_decay_plot.R IP6K2 --global
   ```
   *Also generates `Figure_CHX_GlobalMedian.svg` ($85 \times 65\text{ mm}$) showing proteome-wide median decay with 95% bootstrap confidence bands.*

**Figure Characteristics:**
- **Normalization**: Intensities are normalized to each group's own $0\text{ h}$ mean, isolating decay kinetics from baseline expression differences.
- **Error Bars**: Mean $\pm$ Standard Error (SE) across valid biological replicates with clean horizontal caps.
- **Curves**: Dashed exponential decay fit back-transformed to linear coordinates.
- **Significance Bracket**: Spans the time course with asterisks denoting the proteome-wide BH FDR:
  - `****`: $\text{FDR} < 0.0001$
  - `***`: $\text{FDR} < 0.001$
  - `**`: $\text{FDR} < 0.01$
  - `*`: $\text{FDR} < 0.05$
  - `ns`: $\text{FDR} \ge 0.05$
- **Subtitle**: Reports fitted half-lives: `Parental t1/2 = X.XX h; KO t1/2 = Y.YY h`.
